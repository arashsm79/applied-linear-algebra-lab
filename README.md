# Applied Linear Algebra Lab
Collection of step by step programming exercises to introduce students to the applications of linear algebra.


## Lab#01
v2: 
- Introduction to NumPy
- 3D polygon rendering
- Orthogonal matrices and 3D graphics

v3: 
- Introduction to NumPy 
- Hill Cipher Encryption and Decryption
- Known plaintext attack on Hill Cipher

v4:
- Introduction to NumPy 
- Image processing, including color transformations and channel operations
- 2D and 3D geometric transformations (such as scaling, rotation, shearing, and translation using matrices)

## Lab#02 
v2: 
- QR Decomposition, Modified Gram-schmidt
- Polynomial Regression

v3:

Quantum computing foundations covered in this lab:
- Qubits as vectors in complex vector spaces, superposition, and measurement probabilities
- Vector spaces, basis transformations, inner products, and orthonormalization using Gram-Schmidt
- Quantum gates as linear operators and matrix representations of quantum states
- BB84 Quantum Key Distribution protocol for secure communication using quantum states
